# Better Browsing Chrome Extensions

Enhance your reading experience with Better Browsing. This Chrome extension allows users to customize things such as font family, size, color, as well as giving them access to features such as bionic reading and keyword highlighting, making it easier to read and process information.

## Technology Stack
* **Frontend UI:** Svelte 5 & Tailwind CSS v4 (Reactive, lightning-fast popup interface).
* **Backend:** Vanilla JavaScript (Lightweight DOM manipulation content scripts).
* **Keyword Selection:** Combination of TinyBERT TF-IDF.
